# Диспетчерская служба аэропорта

Desktop-приложение для диспетчерской службы аэропорта. Оно помогает вести справочники авиакомпаний и аэропортов, формировать расписание и контролировать данные рейсов. Пользователь вводит данные в форме, приложение проверяет их, сохраняет в SQLite и отображает актуальные записи в таблицах интерфейса.

## Технологии

- Python 3
- Tkinter/ttk — графический пользовательский интерфейс
- SQLite — встроенная реляционная база данных
- `sqlite3` — подключение приложения к базе данных

## Реализовано

- автоматическое создание базы данных `airport.db`;
- создание таблиц авиакомпаний, аэропортов, самолётов и рейсов;
- начальное заполнение базы тестовыми данными;
- примеры рейсов для демонстрации диспетчерского расписания;
- просмотр списка авиакомпаний;
- добавление авиакомпаний с проверкой IATA-кода;
- просмотр списка аэропортов;
- добавление аэропортов с проверкой IATA-кода;
- создание и просмотр рейсов с выбором авиакомпании, самолёта, аэропортов и статуса;
- формирование отчетов по расписанию, справочникам и статусам рейсов;
- сортировка таблиц по заголовкам столбцов;
- отправка сформированных отчетов на печать системному принтеру Windows;
- проверка времени и запрет маршрута между одинаковыми аэропортами;
- внешние ключи и ограничения целостности данных;
- обработка ошибок при нарушении ограничений базы данных.
- интерактивная справка диспетчера с поиском по темам, кнопкой «Справка» и клавишей F1;
- схема базы данных нормализована минимум до третьей нормальной формы:
  города, модели самолётов и статусы рейсов хранятся в отдельных справочниках.

## Запуск проекта

1. Клонируйте репозиторий и перейдите в его каталог.
2. Создайте виртуальное окружение:

   ```powershell
   python -m venv .venv
   ```

3. Активируйте его в Windows:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

4. Запустите приложение:

   ```powershell
   python main.py
   ```

При первом запуске рядом с `main.py` автоматически создаётся файл `airport.db`.

## Вход в приложение

Перед открытием диспетчерской службы отображается форма авторизации.
Данные для входа по умолчанию:

- логин: `admin`;
- пароль: `admin`.

## Интерактивная справка

Нажмите кнопку «Справка» или клавишу **F1**. В окне справки можно выбрать тему,
получить подсказки для текущего раздела диспетчерской службы и найти нужную информацию по ключевым словам.
Окно закрывается клавишей **Esc**.

## Структура базы данных

Основные таблицы:

- `airlines` — авиакомпании;
- `cities` — города;
- `airports` — аэропорты и ссылки на города;
- `aircraft_models` — модели самолётов;
- `aircrafts` — самолёты и ссылки на модели;
- `flight_statuses` — статусы рейсов;
- `flights` — рейсы и внешние ключи на справочники.
