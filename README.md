# Airport Management System

Desktop-приложение для управления данными аэропорта. Проект демонстрирует полный цикл взаимодействия пользовательского интерфейса с базой данных: пользователь вводит данные в форме, приложение проверяет их, сохраняет в SQLite и отображает актуальные записи в таблицах интерфейса.

## Технологии

- Python 3
- Tkinter/ttk — графический пользовательский интерфейс
- SQLite — встроенная реляционная база данных
- `sqlite3` — подключение приложения к базе данных

## Реализовано

- автоматическое создание базы данных `airport.db`;
- создание таблиц авиакомпаний, аэропортов, самолётов и рейсов;
- начальное заполнение базы тестовыми данными;
- просмотр списка авиакомпаний;
- добавление авиакомпаний с проверкой IATA-кода;
- просмотр списка аэропортов;
- добавление аэропортов с проверкой IATA-кода;
- просмотр рейсов с отображением связанных авиакомпаний, самолётов и аэропортов;
- внешние ключи и ограничения целостности данных;
- обработка ошибок при нарушении ограничений базы данных.

## Запуск проекта

1. Клонируйте репозиторий и перейдите в его каталог.
2. Создайте виртуальное окружение:

   ```powershell
   python -m venv .venv
   ```

3. Активируйте его в Windows:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

4. Запустите приложение:

   ```powershell
   python main.py
   ```

При первом запуске рядом с `main.py` автоматически создаётся файл `airport.db`.

## Структура базы данных

Основные таблицы:

- `airlines` — авиакомпании;
- `airports` — аэропорты и города;
- `aircrafts` — модели самолётов и регистрационные номера;
- `flights` — рейсы и связи между объектами аэропортовой системы.
